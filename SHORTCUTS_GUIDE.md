# ⌨️ OmniWM Shortcuts Guide: Default vs. Layered (Isolated)

This document compares the original "Default" OmniWM shortcuts with your new **Layered & Isolated** system. 

### 🛡️ Why Isolation?
Your new system uses a hidden **Command+Option+Shift** prefix for all internal commands.
*   **Result**: Your physical **Left Option**, **Left Control**, and **Left Command** keys are now **100% FREE** for other apps.
*   **How**: Karabiner captures your `Right Command` or `Right Option` and injects the 3-modifier sequence for you.

---

## 🚀 Navigation & Focus

| Action | Original Default | **Your New Layered Key** |
| :--- | :--- | :--- |
| **Move Focus Up/Down/L/R** | `Ctrl` + `Arrows` | **`Right Option`** + **`WASD`** |
| **Move Window Physically** | `Opt+Shift` + `Arrows` | **`Right Option`** + **`Shift`** + **`WASD`** |
| **Cycle Recent Window** | `Option` + `Tab` | **`Right Option`** + **`Tab`** |
| **Focus Specific Column** | `Ctrl+Opt` + `1-9` | **`Right Option`** + **`1-9`** |

## ⚡ Global Power Features
*   **Caps Lock (Tap)**: Acts as normal Caps Lock.
*   **Caps Lock (Hold)**: Acts as **Hyper** (Cmd+Ctrl+Opt+Shift).
*   **Leader Sequences**:
    *   `Hyper` + `A` (tap) -> `A` (tap) = Launch **Arc**
    *   `Hyper` + `A` (tap) -> `C` (tap) = Launch **Cursor**
    *   `Hyper` + `A` (tap) -> `G` (tap) = Launch **Ghostty**
