# OmniWM Shortcuts Guide (v36 God Build)

Your keyboard is now a high-performance orchestration tool using **BTT-Style Native Modifiers**.

## 🚀 Native Modifiers
*   **Right Command (`RCmd`)**: Master OmniWM Feature Layer.
*   **Right Option (`ROpt`)**: Master Window Focus & Physical Layout Layer.
*   **Left Control + Command**: The standard internal OmniWM chords.

## 💡 Quick Fix for "Fucked Up" Keys
If a hotkey (like palette) isn't working:
1.  Open **OmniWM Settings > Hotkeys**.
2.  Click the hotkey box for that action.
3.  Press **`RCmd + [Key]`** on your keyboard to re-record it without conflicts. mun! 🚀
