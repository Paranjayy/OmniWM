# OmniWM Shortcuts Guide (God-Build V47)

Your keyboard is now a high-performance orchestration tool using **Right-Side Native Layers**.

## 🚀 Native Modifiers
*   **Right Command (`RCmd`)**: Master OmniWM Workspace & System Layer.
*   **Right Option (`ROpt`)**: Master Window Focus & Physical Layout Layer.
*   **Hyper Layer (`⌃⌥⌘⇧`)**: The isolation layer for "annoying" defaults (T, , , .).

## 💡 Quick Tips
*   **Left Mods Reserved**: Avoid using Left Command/Option for OmniWM to prevent app conflicts.
*   **Fine-Tuning**: `ROpt + Shift + Volume/Brightness` triggers native 1/16th steps.
*   **Sync Status**: Ensure `ActiveProfile` is set to `official` to use these ergonomic paths.
