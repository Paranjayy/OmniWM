# ⌨️ OmniWM Shortcuts Guide: Default vs. Layered (Isolated)

This document compares the original "Default" OmniWM shortcuts with your new **Layered & Isolated** system (God-Build V47). 

### 🛡️ Why Isolation (Hyper-Lock)?
Your new system uses a hidden **Command+Option+Shift+Control** (Hyper) prefix for all internal commands that are "annoying" in the official app.
*   **Result**: Your physical **Left Option**, **Left Control**, and **Left Command** keys are now **100% FREE** for other apps.
*   **How**: Karabiner captures your `Right Command` or `Right Option` and injects the 4-modifier sequence for you.

---

## 🚀 Navigation & Focus

| Action | Original Default | **Your New Layered Key** |
| :--- | :--- | :--- |
| **Move Focus Up/Down/L/R** | `Option` + `Arrows` | **`Right Option`** + **`WASD`** |
| **Move Window Physically** | `Opt+Shift` + `Arrows` | **`Right Option`** + **`Shift`** + **`WASD`** |
| **Cycle Width (Fwd/Back)** | `Option` + `./,` | **`Right Option`** + **`. / ,`** |
| **Toggle Tabbed Mode** | `Option` + `T` | **`Right Option`** + **`T`** |

## ⚙️ God-Build Exclusives (Pre-configured)
*   **ROpt + Backspace**: **Trash Window** (Muted for Left side).
*   **ROpt + X**: **Capture Snapshot** (Muted for Left side).
*   **ROpt + H**: **Haptic Test** (Tactile feedback).

## ⚡ Power Features
*   **Caps Lock (Tap)**: Acts as normal Caps Lock.
*   **Caps Lock (Hold)**: Acts as **Hyper** (Cmd+Ctrl+Opt+Shift).
*   **RCmd / ROpt (Hold)**: **WORKSPACE BAR SHOWS**.
*   **RCmd / ROpt (Release)**: **BAR HIDES AFTER 5S**.
